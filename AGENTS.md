# Instrucciones para agentes

Las reglas de este repo están en [`CLAUDE.md`](CLAUDE.md), que es la única fuente. Léelo completo antes de hacer cualquier cosa y síguelo como si estuviera escrito para ti: donde dice "Claude Code", vale para cualquier agente.

Si no eres Claude Code:
- Los skills no se cargan solos. Cuando `CLAUDE.md` nombre un skill, lee `skills/<skill>/SKILL.md` y sigue su flujo.
- Usa los nombres de herramientas MCP que exponga tu cliente; el mapeo está en `skills/_shared/mcp-tools.md`.
- Para coordinarte con el equipo: `team/README.md` y `team/tareas.md`.

No agregues reglas aquí: todo cambio va a `CLAUDE.md`, por PR.
